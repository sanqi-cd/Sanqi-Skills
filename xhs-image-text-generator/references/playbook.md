# 小红书图文生成 Playbook

## 标题公式

### 结果型

- 我用 `<方法/工具>` 拿到了 `<结果>`，完整流程来了
- `<时间周期>` 做到 `<结果>`，我只改了这 `<数字>` 件事
- `<人群>` 用上 `<工具/方法>`，真的能 `<收益>`

### 痛点型

- `<痛点人群>` 进，终于有人把 `<问题>` 讲明白了
- 如果你也 `<痛点>`，先别急着 `<常见错误>`
- `<问题>` 不是你不努力，而是少了这套 `<方法>`

### 清单型

- `<数字>` 个 `<工具/方法/模板>`，建议 `<人群>` 直接收藏
- `<赛道>` 最常用的 `<数字>` 种 `<结构/模板>`
- 普通人学 `<主题>`，先从这 `<数字>` 个场景开始

### 反常识型

- 别再 `<错误做法>` 了，真正有效的是 `<正确做法>`
- `<常识>` 可能错了，爆款图文更吃 `<新观点>`
- 我以为 `<旧认知>`，直到我试了 `<新方法>`

### 教程型

- 5 分钟学会 `<任务>`，新手照做版
- 手把手教你用 `<工具>` 做出 `<结果>`
- 从 0 到 1 搭一套 `<工作流/模板>`

## 封面模板

### 黑底强钩子

适合 AI 工具、效率工具、赚钱副业、强结果类内容。

- 背景：黑色或深色纹理
- 主标题：黄色/白色超大字
- 视觉：真人、工具图标、箭头、截图
- 文案：`这些AI工具`、`替你上班`、`必须装上`

### 白底清单卡

适合教程、工具合集、学习笔记。

- 背景：白色、浅灰或米白
- 主标题：黑色大字 + 一个高亮词
- 视觉：清单、表格、图标矩阵
- 文案：`8种封面设计法`、`2026最佳AI工具`

### 杂志感长图

适合读书笔记、观点拆解、审美内容。

- 背景：低饱和图片或纸张纹理
- 主标题：短句或金句
- 视觉：书本、手写、截图、留白
- 文案：`如果没有天赋，那就一直重复`

### 案例复盘卡

适合运营、增长、职场、项目复盘。

- 背景：真实截图、数据面板、前后对比
- 主标题：结果数字 + 方法
- 视觉：数据、箭头、标注圈、对比框
- 文案：`60万曝光的方法`、`一篇涨粉3000+`

### 痛点场景卡

适合职场、沟通、学习焦虑。

- 背景：办公室、电脑、笔记、聊天截图
- 主标题：痛点人群 + 场景
- 视觉：对话气泡、红色标注、清单
- 文案：`PPT恐惧症进`、`向上汇报别再这样说`

## 分页模板

### 工具清单型

1. 封面：这些工具帮你完成什么结果
2. 痛点：以前这件事为什么慢/难/贵
3. 工具总览：按场景分类
4. 工具 1-2：用途、适合谁、入口
5. 工具 3-4：用途、适合谁、入口
6. 最佳组合：怎么串成工作流
7. 避坑：收费、门槛、国内可用性
8. 总结：适用人群 + 评论领取

### 教程步骤型

1. 封面：5 分钟学会什么
2. 成果预览：最终长什么样
3. 准备材料：输入、工具、账号
4. Step 1：设置/导入
5. Step 2：生成/处理
6. Step 3：优化/发布
7. 常见错误
8. 总结 + 模板领取

### 方法复盘型

1. 封面：结果数字
2. 背景：起点和目标
3. 关键动作总览
4. 动作 1：选题/定位
5. 动作 2：封面/标题
6. 动作 3：发布/互动
7. 数据复盘
8. 可复制清单

### 读书笔记型

1. 封面：书名 + 金句/方法
2. 这本书解决什么问题
3. 核心观点 1
4. 核心观点 2
5. 核心观点 3
6. 我的行动清单
7. 适合谁读
8. 金句总结

## 正文结构

```text
一句话说结果/收获。

适合这些人：
1. ...
2. ...
3. ...

我把内容整理成了几页：
第1页 ...
第2页 ...
第3页 ...

避坑提醒：
...

想要模板/清单/提示词，可以看置顶评论。
```

## 标签生成规则

每篇 12-18 个标签，分 4 类：

- 核心词：主题本身，如 `#AI工具`
- 人群词：目标用户，如 `#打工人效率神器`
- 场景词：应用场景，如 `#提高工作效率的方法`
- 长尾词：搜索意图，如 `#小红书图文怎么写`

## 评论引导

### 置顶评论

- 我来当课代表，资料/模板/工具清单整理好了，先到的宝子蹲一蹲。
- 有人要完整提示词/模板的话，我整理到评论区。
- 大家最想看哪一页的详细教程？我下一篇展开。

### 高频回复

- 是否免费：说明免费额度、付费点和替代方案
- 国内能否用：说明国内可用工具和访问门槛
- 新手能否学：给最低准备条件
- 怎么获取：引导看置顶评论或下一篇
- 是否夸张：说明适用边界，不承诺绝对结果

## 评分细则

- 封面点击力：3 秒内能否看懂收益
- 标题吸引力：是否有人群、痛点、数字、结果
- 保存价值：是否有清单、步骤、模板、工具、对比
- 可信度：是否有案例、数据、截图、亲测经验
- 搜索价值：正文和标签是否覆盖长尾需求
- 评论转化：是否有可回复、可领取、可追问的入口
