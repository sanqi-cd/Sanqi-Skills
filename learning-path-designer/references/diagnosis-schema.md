# 诊断框架

本文件用于补问、诊断和判断学习路径的约束。

- 最小诊断问题

## 最小诊断问题

当用户信息很少时，优先问：

1. 你具体想学什么？
2. 你学它主要是为了什么用途？
3. 你的职业/身份和日常应用场景是什么？
4. 你现在大概是什么基础？每天/每周能投入多少时间？

如果用户已经回答其中大部分，不要重复提问。

## 模糊目标判断

当用户只表达宽泛方向，而没有说明学习目的、职业/身份、应用场景、基础和时间时，属于模糊学习目标。

典型输入：

- 我想系统学习 AI、应用 AI。
- 我想学编程。
- 我想学习数据分析。
- 我想提升写作。
- 我想了解商业、产品、管理。

处理规则：

- 不要直接输出完整学习路径。
- 不要用默认职业、默认用途、默认周期替代真实诊断。
- 先输出 3 个以内的关键问题，引导用户补充背景。
- 可以给用户几个选项帮助回答，但不要替用户选择。
- 可以说明“补充这些信息后，我会为你生成个性化路径”。

## 深度诊断字段

| 字段 | 作用 | 示例 |
|---|---|---|
| 学习领域 | 判断知识范围 | AI 工具、数据安全、Python、写作 |
| 具体目标 | 判断成果形态 | 30 天能在工作中使用、通过考试、做项目 |
| 职业/身份 | 判断场景和难度 | 学生、运营、销售、管理者、开发者、创作者 |
| 当前基础 | 判断阶段和难度 | 小白、学过一点、能做简单任务 |
| 时间投入 | 决定计划密度 | 每天 30 分钟、每周 5 小时 |
| 截止日期 | 判断节奏 | 7 天、30 天、3 个月 |
| 最终用途 | 决定任务场景 | 工作提效、求职、考试、创作 |
| 应用场景 | 决定任务设计 | 写方案、做数据分析、写代码、做选题、客户研究 |
| 学习偏好 | 决定输入形式 | 阅读、视频、实操、案例、项目 |
| 主要困难 | 决定补救策略 | 坚持不了、看不懂、不会用、没反馈 |
| 期望产出 | 决定验证标准 | 作品、报告、证书、文章、演示 |
| 可用资源 | 避免重复推荐 | 已有课程、书、资料、导师 |

## 补问规则

- 缺少学习领域：必须补问。
- 缺少学习目的：必须补问。
- 缺少职业/身份或应用场景：必须补问。
- 缺少当前基础：必须补问，除非用户明确说“小白”“有基础”等。
- 缺少时间投入：优先补问；如果其他背景充分，可以给 2-3 个周期选项，而不是直接默认。
- 缺少周期：优先补问或给周期选项；不要直接默认 30 天，除非用户要求先按默认生成。
- 缺少学习偏好：默认采用「少量输入 + 实操 + 输出 + 复盘」。
- 缺少期望产出：根据任务类型自动建议。

## 诊断引导话术

当目标模糊时，使用这种结构：

```markdown
你现在的目标还比较宽，我先不直接给学习路径，因为 AI/编程/数据分析这类领域会因职业和用途不同，路径差异很大。

请先补充 3 个信息：

1. 你学习它主要为了什么？
   - 工作提效 / 转岗求职 / 内容创作 / 项目落地 / 考试认证 / 个人兴趣

2. 你的职业或身份是什么？最想把它用到哪些日常场景？
   - 例如运营、销售、管理者、学生、开发者、创作者、创业者等

3. 你当前基础和时间约束是什么？
   - 完全小白 / 了解一点 / 做过项目
   - 每天或每周能投入多久，希望多久看到结果
```

## 学习阶段判断

### 0 阶：完全小白

信号：

- 完全没接触过。
- 听过名字，但不知道具体是什么。
- 需要从最基础概念开始。

策略：

- 减少术语。
- 使用类比和示例。
- 用 80/20 找最小入门范围。
- 安排极小任务获得正反馈。

### 1 阶：知道概念但没有体系

信号：

- 看过一些资料。
- 能说出零散术语。
- 不知道知识之间怎么连接。

策略：

- 建知识树。
- 做概念地图。
- 用主题阅读补齐框架。

### 2 阶：有基础但不会应用

信号：

- 能理解资料。
- 做真实任务时卡住。
- 缺少案例和操作经验。

策略：

- 场景化学习。
- 最小可行练习。
- 案例推演。
- 输出倒逼输入。

### 3 阶：能应用但不稳定

信号：

- 会做一些任务。
- 换场景就不稳。
- 容易依赖模板或教程。

策略：

- 刻意练习。
- 交替练习。
- 反馈闭环。
- 复盘错误模式。

### 4 阶：能迁移、输出、教学

信号：

- 能解决真实问题。
- 能讲给别人听。
- 能迁移到新场景。

策略：

- 复杂项目。
- 教学输出。
- 方法沉淀。
- 作品集或研究成果。

## 常见风险诊断

| 风险 | 表现 | 调整 |
|---|---|---|
| 目标过大 | 计划很多但不开始 | 缩成 7 天最小闭环 |
| 输入过散 | 收藏很多资料但没产出 | 限定 1-2 个主资源，增加输出 |
| 难度过高 | 每天都卡住 | 降低任务粒度，补基础示例 |
| 练习不足 | 懂概念但不会做 | 增加拆招训练和项目任务 |
| 反馈不足 | 不知道对错 | 增加测试、点评、对照样例 |
| 复习缺失 | 学了就忘 | 加入主动回忆和间隔重复 |
| 场景缺失 | 学完不知道怎么用 | 转为岗位任务或项目任务 |
