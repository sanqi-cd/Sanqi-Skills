# 路由规则

本文件用于把用户需求映射到方法论组合。输出时不要机械套表，要结合用户实际情况微调。

## 按任务类型路由

| 任务类型 | 首选方法组合 | 重点产出 |
|---|---|---|
| 知识理解型 | 知识树 + 主题阅读 + 费曼输出 + 对比学习 | 知识地图、概念解释、案例说明 |
| 技能掌握型 | 最小可行练习 + 拆招训练 + 刻意练习 + 反馈闭环 | 练习记录、作品、可复用流程 |
| 考试认证型 | 知识树 + 主动回忆 + 间隔重复 + 真题训练 + 错题复盘 | 高频考点表、错题本、模拟成绩 |
| 项目产出型 | 逆向目标拆解 + 项目制学习 + 输出倒逼输入 + 复盘法 | Demo、报告、方案、作品集 |
| 职业提升型 | 能力地图 + 任务驱动学习 + 场景化学习 + 成果证明 | 岗位任务清单、模板、案例库 |
| 研究探索型 | 主题阅读 + 论文三遍阅读法 + 概念地图 + 苏格拉底提问 | 文献矩阵、问题清单、研究框架 |
| 内容创作型 | 输出倒逼输入 + 拆解模仿 + 主题阅读 + 高频输出 + 复盘法 | 选题库、文章、脚本、课程大纲 |

## 按领域特征路由

| 领域特征 | 学习策略 | 注意事项 |
|---|---|---|
| 概念密集型 | 先搭知识树，再用费曼和反例学习吃透概念 | 避免只背术语 |
| 技能操作型 | 先看最小示范，再做拆招练习和项目练习 | 避免只看教程 |
| 体系复杂型 | 先做 MECE 框架和系统图，再用案例填充 | 避免过早钻细节 |
| 记忆密集型 | 高频考点、主动回忆、间隔重复、测试效应 | 避免只读不测 |
| 创造输出型 | 拆解优秀样本、建立输出节奏、获取反馈 | 避免长期准备不发布 |
| 综合复合型 | 分阶段混合方法，先框架，再练习，再迁移 | 避免一次塞满所有方法 |

## 按用户阶段路由

| 阶段 | 策略 | 禁忌 |
|---|---|---|
| 0 阶：完全小白 | 降低术语，使用 80/20、类比学习、最小任务 | 不要给过长书单和复杂项目 |
| 1 阶：有碎片概念 | 建知识树、概念地图、主题阅读 | 不要继续无序刷资料 |
| 2 阶：懂但不会用 | 场景化学习、最小可行练习、案例推演 | 不要只做笔记 |
| 3 阶：能用但不稳 | 刻意练习、反馈闭环、交替练习 | 不要只重复舒适任务 |
| 4 阶：能迁移输出 | 研究、教学、作品集、复杂项目 | 不要停留在基础练习 |

## 按周期路由

- 1-7 天：只做最小闭环，目标是入门、判断方向或完成一个小产出。
- 14 天：建立基础框架，并完成 2-3 个练习或小作品。
- 30 天：适合形成入门能力、完成一个可展示成果。
- 90 天：适合系统掌握、作品集、转岗准备或考试备考。
- 超过 90 天：拆成多个 30 天阶段，每阶段有明确产出和复盘。

## 常见场景组合

### 小白学 AI 工具

任务驱动学习 + 80/20 学习法 + 最小可行练习 + 项目制学习 + 复盘法。

优先围绕真实工作场景：写文档、做 PPT、整理资料、分析数据、自动化流程。

### 职场人学数据分析

能力地图 + 任务驱动学习 + 案例学习 + 项目制学习 + 反馈闭环。

优先产出：业务指标表、分析报告、仪表盘、复盘案例。

### 学生备考

知识树 + 主动回忆 + 间隔重复 + 真题训练 + 错题复盘。

优先产出：考点地图、错题本、模拟测试记录。

### 程序员学习新技术

80/20 学习法 + 最小可行项目 + 源码或文档精读 + 刻意练习 + 项目复盘。

优先产出：Demo、代码片段库、踩坑记录、技术分享。

### 内容创作者学习新领域

主题阅读 + 知识树 + 输出倒逼输入 + 拆解模仿 + 高频发布。

优先产出：选题库、素材卡片、系列文章、视频脚本。
