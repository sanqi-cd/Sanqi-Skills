# 方法论库

本文件用于帮助选择学习方法。不要一次性把所有方法输出给用户，只选择最匹配的 3-5 个。

## 目录

- 目标拆解类
- 知识建模类
- 高效输入类
- 深度理解类
- 记忆巩固类
- 技能训练类
- 迁移应用类
- 反馈迭代类

## 1. 目标拆解类

适合：目标模糊、想快速明确学习范围、职场提升、项目学习、转岗学习。

- 第一性原理：追问这个领域最底层的问题、对象、关系和约束。
- 逆向目标拆解：从最终成果倒推需要掌握的能力和任务。
- OKR 学习法：用目标和关键结果定义阶段成果。
- 能力地图法：把目标拆成知识、技能、工具、场景、作品和证明材料。
- 任务驱动学习：围绕真实任务组织学习，而不是围绕目录学习。

不优先使用：用户只是想快速了解一个概念时，不必做复杂目标拆解。

## 2. 知识建模类

适合：体系复杂、概念多、资料碎片化、需要建立长期认知框架。

- 知识树：将领域拆成模块、概念、关系和案例。
- 概念地图：表达概念之间的因果、包含、对比、依赖关系。
- MECE 拆解：让知识分类尽量互斥且完整。
- 系统思维：关注结构、反馈、边界、变量和相互影响。
- 类比学习：用熟悉领域理解陌生概念。
- 费曼学习法：用简单语言讲清楚，暴露理解漏洞。

不优先使用：纯操作技能的第一小时学习，不要先搭过大的知识树。

## 3. 高效输入类

适合：资料很多、时间有限、需要快速入门或研究一个主题。

- 80/20 学习法：优先抓住最常用、最高价值的 20%。
- SQ3R 阅读法：浏览、提问、阅读、复述、复习。
- 主题阅读法：围绕一个问题阅读多份资料并比较观点。
- 信息分层阅读：先结论和框架，再细节和证据。
- 论文三遍阅读法：第一遍看结构，第二遍看方法和证据，第三遍精读和复现。

不优先使用：考试冲刺后期应增加真题和主动回忆，而不是继续大量输入。

## 4. 深度理解类

适合：概念抽象、容易一知半解、需要讲解、写作、研究或迁移。

- 费曼输出：不用术语也能讲给外行听。
- 苏格拉底提问：持续追问定义、前提、证据、反例和边界。
- 第一性原理追问：还原到底层事实和约束。
- 案例推演：用真实案例验证概念。
- 反例学习：通过失败案例、边界情况和例外理解概念。
- 对比学习：比较相似概念、相邻工具、不同方案。

不优先使用：短期机械记忆任务不必过度做理论推演。

## 5. 记忆巩固类

适合：语言、考试、证书、医学、法律、法规、术语、命令、题型。

- 主动回忆：合上资料后自己提取答案。
- 间隔重复：按遗忘规律安排复习。
- 测试效应：通过测试增强记忆。
- 错题本：记录错误原因、正确解法、相似题和复习日期。
- Anki 卡片法：将知识转成问答卡片。
- 交替练习：混合不同题型或场景，提升辨别能力。

不优先使用：创造型任务不能只靠记忆，需要作品和反馈。

## 6. 技能训练类

适合：AI 工具、编程、写作、设计、销售、演讲、剪辑、数据分析等。

- 刻意练习：针对薄弱点进行高反馈、高重复训练。
- 拆招训练：把复杂技能拆成可单独练习的小动作。
- 最小可行练习：用最小任务快速开始并获得反馈。
- 项目制学习：边学边完成一个真实项目。
- 作品驱动学习：以可展示作品作为学习成果。
- 反馈闭环：练习、反馈、修正、再练习。

不优先使用：完全没有基础概念时，需要少量输入和示范再开始练习。

## 7. 迁移应用类

适合：职场应用、项目交付、真实场景落地、从会学到会用。

- PBL 项目式学习：围绕问题或项目学习。
- 场景化学习：把知识放进真实使用场景。
- 案例学习：从真实案例中学习判断和做法。
- 输出倒逼输入：先定义产出，再选择输入资料。
- 模拟任务训练：模拟汇报、面试、客户沟通、项目交付。
- 角色扮演：切换用户、客户、管理者、评审者等视角。

不优先使用：对 0 阶小白应降低项目难度，避免直接上复杂实战。

## 8. 反馈迭代类

适合：所有中长期学习，尤其是进展不稳定、容易放弃、目标变化的学习。

- PDCA：计划、执行、检查、调整。
- 复盘法：记录事实、结果、原因、经验和下一步。
- 双环学习：不仅修正行动，也修正目标和假设。
- 元认知监控：观察自己是否真的理解、是否在逃避难点。
- 学习日志：记录投入、产出、困难、调整和证据。

不优先使用：一次性查询类问题不需要完整复盘体系。
