## 示例一：职场小白学 AI 工具

用户输入：

> 我是职场白领，想 30 天学会 AI 工具提升工作效率，每天 1 小时，之前没系统学过。

推荐判断：

- 主任务类型：技能掌握型 + 职业提升型。
- 领域特征：技能操作型 + 综合复合型。
- 当前阶段：0 阶到 1 阶之间。
- 方法组合：任务驱动学习 + 80/20 学习法 + 最小可行练习 + 项目制学习 + 每周复盘。

路径重点：

- 不从 AI 原理开始，而从高频办公任务开始。
- 先完成文档、资料整理、PPT、表格分析、会议纪要等任务。
- 每周沉淀一组可复用提示词和工作流。

阶段产出：

- 第 1 周：10 个岗位常用提示词。
- 第 2 周：3 个真实办公任务成品。
- 第 3 周：1 套个人 AI 工作流。
- 第 4 周：1 份 AI 提效案例复盘。

## 示例一补充：模糊目标先诊断

用户输入：

> 我是小白，当前想系统学习 AI、应用 AI。

推荐处理：

- 不直接输出完整 30 天路径。
- 判断该输入缺少学习目的、职业/身份、应用场景、时间约束。
- 先输出学习诊断引导。

示例回复方向：

```markdown
你现在的目标是“系统学习 AI、应用 AI”，但这个目标还比较宽。我先不直接给完整学习路径，因为 AI 对职场人、学生、开发者、创作者、管理者的路径差异很大。

请先补充 3 个信息：

1. 你学习 AI 主要为了什么：工作提效、转岗求职、内容创作、项目开发、研究探索，还是个人兴趣？
2. 你的职业/身份是什么？最想把 AI 用到哪些日常场景？
3. 你每天/每周能投入多久，希望多久看到结果？
```

## 示例二：学生备考证书

用户输入：

> 我想两个月通过一个专业证书考试，基础一般，平时每天能学 2 小时。

推荐判断：

- 主任务类型：考试认证型。
- 领域特征：记忆密集型 + 概念密集型。
- 当前阶段：1 阶或 2 阶。
- 方法组合：知识树 + 主动回忆 + 间隔重复 + 真题训练 + 错题复盘。

路径重点：

- 先搭考点地图，不盲目通读教材。
- 每天固定主动回忆和刷题。
- 每周一次模拟测试，按错题反推薄弱考点。

阶段产出：

- 考点地图。
- 高频考点卡片。
- 错题本。
- 模拟测试记录。

## 示例三：内容创作者学习新领域

用户输入：

> 我想系统学习 AI Agent，然后写成公众号系列文章。

推荐判断：

- 主任务类型：内容创作型 + 研究探索型。
- 领域特征：体系复杂型 + 概念密集型 + 创造输出型。
- 当前阶段：根据用户基础判断。
- 方法组合：主题阅读 + 知识树 + 输出倒逼输入 + 对比学习 + 高频发布复盘。

路径重点：

- 学习路径和内容产出绑定。
- 每个模块都产出一篇文章或一个案例拆解。
- 建立概念地图、案例库、产品对比表和选题库。

阶段产出：

- AI Agent 知识树。
- 10 个选题。
- 5 个案例拆解。
- 3-5 篇系列文章。

## 示例四：程序员学习新技术

用户输入：

> 我会一点后端，想一个月学会 LangGraph 并做一个 Agent 项目。

推荐判断：

- 主任务类型：技能掌握型 + 项目产出型。
- 领域特征：技能操作型 + 体系复杂型。
- 当前阶段：2 阶。
- 方法组合：80/20 学习法 + 最小可行项目 + 文档精读 + 拆招训练 + 项目复盘。

路径重点：

- 先跑通最小 Demo。
- 再拆解状态、节点、边、工具调用、记忆、错误处理。
- 最后完成一个可展示 Agent 项目。

阶段产出：

- 最小 Demo。
- 关键概念笔记。
- Agent 项目。
- 技术分享或项目复盘。
