## 学习诊断引导模板

用于用户目标模糊、背景不足时。此时不要输出完整学习路径。

```markdown
# 学习诊断引导

你现在的目标是：

> [复述用户的模糊目标]

这个目标还比较宽，我先不直接给完整学习路径。因为同一个领域在不同职业、用途和基础下，学习路线会差很多。

请先补充 3 个信息：

## 1. 你学习它主要为了什么？

可以选一个或多个：

- 工作提效
- 转岗求职
- 项目落地
- 内容创作
- 考试认证
- 研究探索
- 个人兴趣

## 2. 你的职业/身份是什么？想用到哪些场景？

例如：

- 学生：学习、作业、科研、求职
- 职场人：文档、方案、数据分析、汇报、流程自动化
- 创作者：选题、写作、脚本、图片、视频
- 开发者：代码、Agent、自动化、产品开发
- 管理者：决策、会议、团队协作、业务分析
- 销售/运营：客户研究、活动策划、增长分析、话术优化

## 3. 你当前基础和时间约束是什么？

- 当前基础：完全小白 / 了解一点 / 能做简单任务 / 已经有项目经验
- 时间投入：每天或每周能学多久
- 期望周期：7 天入门 / 30 天能用 / 90 天系统掌握 / 其他

你回复这 3 点后，我会根据你的实际情况生成：

- 学习任务类型判断
- 方法论组合
- 知识树和任务树
- 阶段路径
- 每日/每周执行计划
- 产出物和验证标准
- 复盘调整机制
```
